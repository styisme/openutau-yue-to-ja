## 一、插件简介

YueToJapanesePhonemizer（简称 YUE to JA）是一个 OpenUtau 音素器插件，让日语音源（CV / VCV / CVVC）直接演唱粤语歌词。

**工作原理：**

```
粤语歌词 → 粤拼（Jyutping）→ 日语 mora 序列 → 匹配音源别名 → 渲染歌声
```

你在音符里输入汉字或粤拼，插件自动完成后续所有转换。

## 二、系统要求

| 项目 | 要求 |
| ---- | ---- |
| OpenUtau | v0.1.570 或更高（官方 win-x64 编译版） |
| 操作系统 | Windows 10 / 11（x64） |
| 音源 | 任何日语音源（CV、VCV、CVVC） |
| 运行时 | .NET 10 Desktop Runtime |

> 本插件针对 OpenUtau 官方 .NET 10 版本编译。如果你使用的是旧版 OpenUtau（.NET 8 时代），插件将无法加载，请先升级 OpenUtau。

## 三、安装步骤

### 方式一：安装包（推荐）

1. 双击 `MyYUtoJAPlugin-v1.0.0-Setup.exe`
2. 按提示下一步
3. 安装程序会自动探测 OpenUtau 的 Plugins 目录（通常在 `<文档目录>\OpenUtau\Plugins\`）
4. 如果探测失败，手动浏览到你自己的 Plugins 目录即可

### 方式二：手动安装

#### 第一步：找到 OpenUtau 数据目录

新版 OpenUtau 的插件目录通常在用户文档下：

```text
<文档目录>\OpenUtau\
├── Plugins\          ← 插件放这里
├── Singers\
└── Cache\
```

> **提示：** 旧版便携版可能位于安装目录下的 `Plugins\` 文件夹。如果两个位置都有，都放一份最保险。

#### 第二步：关闭 OpenUtau

务必完全退出 OpenUtau：

1. 关闭主窗口
2. 打开任务管理器（Ctrl + Shift + Esc）
3. 确认没有 `OpenUtau.exe` 在运行

> ⚠️ **如果 OpenUtau 正在运行，插件 DLL 会被锁定，复制会失败或 DLL 消失。**

#### 第三步：复制插件 DLL

把 `MyYUtoJAPlugin.dll` 复制到 Plugins 文件夹：

```text
<文档目录>\OpenUtau\Plugins\MyYUtoJAPlugin.dll
```

复制完成后 Plugins 目录里应该有：

```text
Plugins\
├── MyYUtoJAPlugin.dll   ← 本插件
├── yue2ja.yaml          ← 配置文件（可选）
└── （其他原有插件）
```

#### 第四步：启动 OpenUtau 验证

1. 双击 `OpenUtau.exe` 启动
2. 新建一个音轨，或打开已有工程
3. 在音轨设置面板里找到 **音素器（Phonemizer）** 下拉菜单
4. 列表中应该出现：**"YUE to JA"** 或 **"Cantonese to Japanese Phonemizer"**

看到它就说明安装成功。

## 四、使用方法

### 1. 选择音素器

在音轨设置里，把音素器切换为 **"YUE to JA"**。

### 2. 输入歌词

在钢琴卷帘中双击音符，输入汉字：

| 音符 | 输入 |
| ---- | ---- |
| 1 | 你 |
| 2 | 好 |
| 3 | 世 |
| 4 | 界 |

**规则：一个音符 = 一个字。** 不要把一句话塞进同一个音符。

### 3. 用粤拼输入（推荐）

遇到多音字或生僻字时，**直接输入粤拼更可靠**：

```text
nei5  hou2  sai3  gaai3
```

声调数字可省略：

```text
nei  hou  sai  gaai
```

一个音符里也可以用空格分隔多个粤拼音节，插件会把它们分配到同一个音符的多个 mora：

```text
你  (一个音符)
好  (一个音符)
```

### 4. 特殊符号

| 符号 | 作用 | 使用场景 |
| ---- | ---- | -------- |
| `-` | 起始标记 | 放在乐句第一个音符，表示从静音开头 |
| `R` | 尾音收尾 | 放在乐句最后一个音符，让尾音自然衰减 |
| `+` | 延音 | 让上一个字的发音延长到当前音符 |
| `吸入` | 换气声 | 需要一个明显的呼吸点时使用 |

### 5. 多音字处理

粤语多音字非常多。插件的处理方式：

**方法一：直接写粤拼**

把「行」改成 `haang`（走）或 `hang`（银行）。

**方法二：使用音素提示**

右键音符 → 选择 **"音素提示"**（Phonetic Hint）→ 输入粤拼，覆盖默认转换。

### 6. 声调控制

粤拼声调写在音节末尾（1–6），影响末尾 mora 的时长：

```text
nei5   你  (第 5 声)
hou2   好  (第 2 声)
```

不需要声调时可以省略，插件用默认时长。

### 7. 渲染与试听

填完词后，点击 **渲染（Render）** 按钮。如果一切正常，就能听到日语音源唱出的粤语。

### 8. 更换 DLL / YAML 后必做

⚠️ 每次更换插件 DLL 或修改 `yue2ja.yaml` 后，请执行：

1. 完全退出 OpenUtau
2. 复制新的 DLL 到 `Plugins\`
3. **清空** `Documents\OpenUtau\Cache\` 里的内容
4. 启动 OpenUtau，重新渲染

不清缓存会导致 OpenUtau 继续播放旧音素器生成的音频，你改了参数也听不到效果。

## 五、粤拼速查

粤拼（Jyutping）是香港语言学学会制定的粤语拼音方案，用拉丁字母表示粤语发音。

### 声母

| 粤拼 | 例字 | 近似普通话 |
| ---- | ---- | ---------- |
| `b` | 爸 baa | 爸 |
| `p` | 怕 paa | 怕 |
| `m` | 妈 maa | 妈 |
| `f` | 花 faa | 花 |
| `d` | 打 daa | 打 |
| `t` | 他 taa | 他 |
| `n` | 那 naa | 那 |
| `l` | 啦 laa | 啦 |
| `g` | 家 gaa | 家 |
| `k` | 卡 kaa | 卡 |
| `h` | 哈 haa | 哈 |
| `ng` | 牙 ngaa | （无） |
| `gw` | 瓜 gwaa | 瓜 |
| `kw` | 夸 kwaa | 夸 |
| `w` | 蛙 waa | 蛙 |
| `z` | 渣 zaa | 渣 |
| `c` | 叉 caa | 叉 |
| `s` | 沙 saa | 沙 |
| `j` | 也 jaa | 也 |

### 韵母

| 粤拼 | 例字 | 粤拼 | 例字 |
| ---- | ---- | ---- | ---- |
| `aa` | 沙 saa | `a` | 心 sam |
| `e` | 写 se | `i` | 诗 si |
| `o` | 梳 so | `u` | 夫 fu |
| `yu` | 书 syu | `oe` | 靴 hoe |
| `eo` | 需 seoi | `ai` | 大 daai |
| `au` | 走 zau | `ei` | 你 nei |
| `ou` | 好 hou | `iu` | 小 siu |
| `ui` | 水 seoi | `aai` | 街 gaai |
| `aau` | 搞 gaau | `oeng` | 香 hoeng |
| `eon` | 春 ceon | `ing` | 星 sing |
| `ung` | 中 zung | `yun` | 冤 jyun |

### 声调

粤语有 6 个声调，数字 1–6 写在音节末尾：

| 数字 | 调值 | 例字 | 时长效果 |
| ---- | ---- | ---- | -------- |
| 1 | 高平 | 诗 si1 | 正常 |
| 2 | 高升 | 史 si2 | 略短 |
| 3 | 中平 | 试 si3 | 正常 |
| 4 | 低降 | 时 si4 | 略短 |
| 5 | 低升 | 市 si5 | 略长 |
| 6 | 低平 | 事 si6 | 最短 |

### 入声韵尾

粤语保留古汉语的入声韵尾 `-p` / `-t` / `-k`，发音短促：

| 韵尾 | 例字 |
| ---- | ---- |
| `-p` | 十 sap、入 jap |
| `-t` | 一 jat、八 baat |
| `-k` | 六 luk、百 baak |

日语没有对应塞音韵尾，插件会**丢弃尾音**，只保留主元音。

## 六、发音特点

由于粤语和日语的音系差异，转换出来的发音会带有"日式粤语"特色，属于正常现象：

| 粤语 | 粤拼 | 日语近似 | 说明 |
| ---- | ---- | -------- | ---- |
| 早 | zou | じょう | 复韵母合并 |
| 我 | ngo | ご | 鼻音声母近似 |
| 香 | hoeng | へ ん | 元音 + 鼻音韵尾 |
| 入 | jap | や | 入声尾音丢弃 |
| 粤 | jyut | ゆ | 圆唇元音近似 |
| 唔 | m | ん | 独立鼻音 |

**一句话总结：听起来像日本人唱粤语，而不是标准粤语。** 这是跨语言音源的固有限制，不是 Bug。

## 七、YAML 配置

插件启动时会自动读取以下位置的 `yue2ja.yaml`：

1. `<文档目录>\OpenUtau\Plugins\yue2ja.yaml`（全局配置）
2. `<音源目录>\yue2ja.yaml`（该音源专属配置，优先级更高）

没有这个文件时，插件使用内置默认值。

### 完整示例

```yaml
# yue2ja.yaml

# 鼻音韵尾处理
nasal_mode: short       # none / short / full
nasal_ms: 120           # short 模式「ん」占音符末尾毫秒

# 通配符过渡音素
use_wildcard: true

# 关闭开关
disable_vcv: false
disable_light_tone: false
disable_tone_timing: false
disable_double_char: false

# 自定义粤拼 → 日语 mora 映射（覆盖内置）
# full_jyutping:
#   nei: [ne, i]
#   hou: [ho, u]

# 多音字修正（连续音节）
# polyphones:
#   "ngan haang": "ngan hang"

# 别名覆盖（弱音源想用短别名时）
# alias_overrides:
#   "ん": ["ん -", "n -", "n"]
```

### 参数说明

| 参数 | 默认 | 说明 |
| ---- | ---- | ---- |
| `nasal_mode` | `short` | 鼻音韵尾处理，见第八章 |
| `nasal_ms` | `120` | `short` 模式下「ん」占末尾毫秒数（30–500） |
| `use_wildcard` | `true` | 优先尝试 `*` 过渡音素 |
| `disable_vcv` | `false` | 禁用 VCV 过渡 |
| `disable_light_tone` | `false` | 禁用叠字缩短 |
| `disable_tone_timing` | `false` | 禁用声调时长微调 |
| `disable_double_char` | `false` | 禁用叠字处理 |

## 八、鼻音与入声处理

### 鼻音韵尾（ん）

粤语有 `-m` / `-n` / `-ng` 三种鼻音韵尾，转换到日语时生成「ん」音素。

不同音源的「ん」采样长度差异很大，本插件提供三档：

| 模式 | 行为 | 适用场景 |
| ---- | ---- | -------- |
| `none` | 完全不生成「ん」 | 想要干净、不带鼻音 |
| `short`（默认） | 「ん」只占音符末尾固定毫秒 | 保留鼻音但不拖长 |
| `full` | 保留完整「ん」采样 | 想要明显的鼻音效果 |

**⚠️ 重要提醒：**

「ん」的物理播放时长由音源的 `oto.ini` 决定，音素器无法改变采样本身的长度。`short` 模式只是把「ん」的起始位置推迟到音符末尾，因此：

- 普通音源（ん 采样 50ms 左右）→ `short` 模式效果明显
- 弱音源 / 气声音源（ん 采样 150ms+）→ `short` 模式效果有限，仍会偏长

如果 `short` 也没用，请改用**分音符**方式，这是唯一 100% 精确的方案：

```text
音符1: sa     ← 主元音
音符2: n      ← 单独的「ん」，音符长度决定实际时长
```

### 入声韵尾（-p / -t / -k）

粤语入声字（如「十 sap」「一 jat」「六 luk」）的尾音在日语里没有对应，插件会**丢弃尾音**，只保留主元音：

| 粤拼 | 输出 | 说明 |
| ---- | ---- | ---- |
| sap | さ | -p 丢弃 |
| jat | や | -t 丢弃 |
| luk | る | -k 丢弃 |

如果某些字听起来太短，可以用「音素提示」手动补一个促音 `っ`。

## 九、常见问题

### Q1：音素器列表里找不到 "YUE to JA"？

排查顺序：

1. 确认插件文件位置正确：应该在 `<文档目录>\OpenUtau\Plugins\` 下
2. 确认文件名完整：不能是 `MyYUtoJAPlugin.dll.txt` 或带 `(1)` 后缀
3. 查看日志：菜单栏「帮助」→「显示日志」，搜索 `YUE to JA`
4. 重启 OpenUtau：有时候需要完全退出再启动

### Q2：改了 YAML / 换了 DLL，效果没变化？

**这是 OpenUtau 的缓存机制。**

OpenUtau 会缓存已渲染的音频片段，音符内容不变就不会重新渲染。换完插件后必须：

1. 完全关闭 OpenUtau
2. 清空 `<文档目录>\OpenUtau\Cache\` 里的内容
3. 重新启动并渲染

### Q3：渲染时报 `Oto not found for "ゃ"`？

**这是正常的。**

「ゃ」是日语拗音（みゃ / きゃ / しゃ 等）的小写后缀，不是独立的 mora。OpenUtau 渲染时会做边界探测，把「みゃ」拆成「み」和「ゃ」分别尝试查找 OTO。该警告可以忽略，声音会正常播放。

### Q4：DLL 复制进去后消失了？

**原因：**

- OpenUtau 正在运行，锁定了文件
- 你复制的是与官方内置插件同名的文件，被 OpenUtau 自动清理

**解决：**

1. 完全关闭 OpenUtau（任务管理器确认）
2. 使用独立文件名 `MyYUtoJAPlugin.dll`
3. 重新复制，然后启动 OpenUtau

### Q5：某些字发音很奇怪？

可以尝试：

1. **直接用粤拼输入** —— 最可靠。粤语多音字多，汉字转粤拼可能选错读音
2. 使用音素提示：右键音符 → 音素提示 → 手动指定发音
3. 换音源测试：不同音源的发音习惯差异很大
4. 反馈问题：把出问题的字和音源型号反馈给插件作者

### Q6：ん 听起来太长怎么办？

先确认 `yue2ja.yaml` 里的 `nasal_mode` 是 `short` 还是 `none`。如果已经是 `short` 但还长，说明你的音源「ん」采样本身就很长。此时：

- **方案一：** 改成 `nasal_mode: none`，直接省略鼻音
- **方案二：** 分两个音符写 `a` + `n`，用音符长度精确控制
- **方案三：** 调小 `nasal_ms`（如 60），能榨出一点效果

### Q7：入声字（一、六、十）听起来太短？

粤语入声字在日语里没有对应尾音，插件会自动丢弃。如果听起来太短：

1. 用「音素提示」手动补促音 `っ`
2. 或者用「分音符」方式，把入声字拆成两个音符

### Q8：能和官方内置的 "JA VCV" 或 "JA CVVC" 同时使用吗？

**可以。** 本插件使用独立文件名 `MyYUtoJAPlugin.dll`，不会与 OpenUtau 内置的音素器冲突。你可以在不同音轨上选择不同音素器。

### Q9：怎么让插件读数字？

插件会自动把阿拉伯数字转成粤语读法。支持：

- 单个数字：`5` → `ng`
- 双位数：`25` → `ji sap ng`
- 长数字（逐位读）：`2024` → `ji ling ji sei`
- 日期：`2024-01-15` → `ji ling ji sei nin jat jyut sap ng jat`
- 时间：`12:30` → `sap ji dim saam sap fan`
- 小数：`3.14` → `saam dim jat sei`
- 百分比：`50%` → `baak fan zi ng sap`
- 千位逗号：`1,000` → `jat ling ling ling`

### Q10：粤拼的声调数字和歌词混在一起了怎么办？

声调数字只识别**紧跟在拉丁字母后面**的情况，如 `nei5`。如果歌词本身是数字（如「一二三」），会被正常当作数字读。

## 十、卸载方法

### 安装包安装

到「控制面板 → 程序和功能」找到 `YueToJapanesePhonemizer` 卸载。

### 手动安装

1. 完全关闭 OpenUtau
2. 删除 `<文档目录>\OpenUtau\Plugins\MyYUtoJAPlugin.dll`
3. （可选）删除同目录下的 `yue2ja.yaml`
4. 重新启动 OpenUtau

**不会影响 OpenUtau 的任何其他功能。**
